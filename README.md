1. Módulo de periodos.

a. Debe existir siempre un periodo abierto. Un periodo no puede ser cerrado si no existe otro periodo abierto.

b. Periodos cuyo año sea menor al año actual – 1, no pueden ser modificados.

2. Módulo de Carreras.

a. Agregar una pantalla que muestre todas las carreras en una tabla, con las columnas nombre de la carrera y el campo activo, otra columna denominada operaciones.

b. En la columna operaciones deben aparecer 2 botones, el primero debe ser “Modificar” y el segundo “Relacionar Carrera”.

c. El botón “Modificar” entra a una pantalla donde se muestra el registro a editar, en esta pantalla se debe permitir alterar el registro siempre y cuando todos los datos existan.

d. El botón “Relacionar Carrera” entra a una pantalla que mostrará la información de la carrera seleccionada y varias CheckBox, una por cada plantel, seleccionadas las opciones donde la carrera se oferte. Se debe permitir editar las opciones por si la carrera se deje de ofertar o agregar en un nuevo plantel.

3. Módulo de laboratorios.

a. Agregar una pantalla que muestre todos los laboratorios existentes en una tabla, con las columnas nombre del laboratorio, Nombre del Edificio y si está activo.

b. La carga de la tabla de laboratorios existentes debe ser tener un filtro por plantel.

4. Módulo de materias.

a. Al seleccionar un registro en la tabla para modificarlo, se debe mostrar el registro seleccionado para edición.

b. Las claves para la materia deben ser 3 a 4 letras seguidas de un número entero de máximo 4 dígitos. Ejemplo: ISCV24, ACF1394

5. Todo el sistema:

a. Cada Select o ComboBox debe tener la opción para filtrar las opciones que maneje.

6. Registro uso de laboratorio:

a. Cuando se cargue la pantalla debe aparecer la fecha en formato dd/MM/yyyy en el campo de fecha de sesión. No debe permitir edición. Si el dato no se genera no debe permitir guardar.

b. Cuando se cargue la pantalla debe aparecer en el campo Clave Docente, el nombre de usuario con que se loguea la cuenta. No debe permitir edición. Si el dato no existe no debe permitir guardar.

c. El select relacionado a la materia debe cargar únicamente los datos relacionados con la carrera que se selecciona.

d. El select de periodo solo debe cargar los periodos que no estén cerrados.

7. Agregar en el Login, una opción para dar de alta a profesores en el sistema:

a. Solo aplica para el rol de docente.

b. Se debe enviar un correo con los datos de la cuenta (Usuario y Contraseña), al correo indicado en el registro.

8. Realizar los reportes definidos en los archivos de Excel anexos
